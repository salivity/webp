Animated WebP Disposal Method for Transparency

Animated WebP images rely on frame-level disposal methods to control how previous visual data is cleared before the next frame is rendered. To restore the canvas area to full transparency, animated WebP uses the "Dispose to background color" method (represented as disposal method 1) combined with an alpha value of zero in the container's background color settings. This article explains how this disposal method functions within the WebP file format specifications, how it clears previous frame content, and how it interacts with the canvas.

The WebP Animation Disposal Mechanism

Unlike the GIF format, which provides four distinct disposal methods, the WebP container specification simplifies frame disposal down to a single 1-bit flag inside the Animation Frame (ANMF) chunk.

This 1-bit flag defines two operational states:

  • Method 0 (Do Not Dispose): Leaves the current frame on the canvas. The next frame renders directly on top of the existing pixels without clearing the previous frame’s area.
  • Method 1 (Dispose to Background Color): Clears the rectangular region occupied by the current frame on the canvas, filling it with the background color specified in the animation's header chunk before the subsequent frame is drawn.

Restoring Canvas to Full Transparency

To achieve full transparency upon disposal, WebP couples Disposal Method 1 with the animation metadata defined in the ANIM (Animation Control) chunk:

  1. The Background Color Parameter: The ANIM chunk contains a 32-bit field specifying the default canvas background color in blue, green, red, and alpha (BGRA) byte order.
  2. Setting the Alpha Channel: When this 32-bit background color has an alpha channel value of 0x00 (such as 0x00000000 for transparent black), applying Disposal Method 1 fills the frame rectangle with full transparency.
  3. Execution: Once the frame display duration finishes, the decoder erases the pixels bounded by that frame’s width, height, and offset coordinates, returning that specific canvas area back to fully transparent pixels.

Disposal vs. Blending in WebP

Achieving clean transparency also depends on separating frame disposal from frame blending:

  • Disposal dictates what happens to the area after the frame has finished its duration and before the next frame is drawn.
  • Blending (controlled by a separate 1-bit flag in the ANMF chunk) determines how the incoming frame is composited onto the canvas. Setting blending to "do not blend" (0) completely replaces canvas pixels with the new frame's pixels, whereas "blend" (1) uses alpha blending.

To completely reset an area to transparency between changes, developers and encoding tools configure the outgoing frame with Disposal Method 1 ("Dispose to background color") and guarantee the file's global canvas background color contains an alpha value of zero.
