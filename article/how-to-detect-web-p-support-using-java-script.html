How to Detect WebP Support Using JavaScript

Detecting client-side WebP decoding support ensures web applications deliver optimized media without breaking visual presentation on unsupported clients. While modern browsers almost universally support WebP, client-side feature detection is still essential for edge cases, legacy environments, and specific WebP sub-formats like lossless or animated images. JavaScript provides several APIs to detect this support, primarily through the HTMLImageElement decoding method, the Canvas API, and the ImageBitmap API.

1. The HTMLImageElement and decode() API

The standard and most accurate approach to detect WebP decoding is creating an in-memory HTMLImageElement, loading a minimal WebP data URI, and using the asynchronous decode() method.

async function checkWebPSupport() {
  if (!window.HTMLImageElement || !HTMLImageElement.prototype.decode) {
    return false;
  }

  const img = new Image();
  img.src = 'data:image/webp;base64,UklGRiQAAABXRUJQVlA4IBgAAAAwAQCdASoBAAEAAwA0JaQAA3AA/vuUAAA=';

  try {
    await img.decode();
    return true;
  } catch {
    return false;
  }
}

If the environment does not support img.decode(), you can fall back to standard onload and onerror event listeners on the Image object.

function checkWebPSupportFallback(callback) {
  const img = new Image();
  img.onload = () => callback(img.width > 0 && img.height > 0);
  img.onerror = () => callback(false);
  img.src = 'data:image/webp;base64,UklGRiQAAABXRUJQVlA4IBgAAAAwAQCdASoBAAEAAwA0JaQAA3AA/vuUAAA=';
}

2. The Canvas API (toDataURL)

The HTMLCanvasElement provides a synchronous method for detecting WebP encoding and decoding via the toDataURL() method. When requesting an unsupported MIME type, the browser defaults to exporting as image/png.

function checkWebPCanvasSupport() {
  const canvas = document.createElement('canvas');
  if (!canvas.getContext || !canvas.getContext('2d')) {
    return false;
  }
  return canvas.toDataURL('image/webp').indexOf('data:image/webp') === 0;
}

Note: While this method is fast and synchronous, it strictly detects if the canvas can export (encode) to WebP. In most consumer browsers, export support matches decoding support, but discrepancies can occur on constrained devices.

3. The createImageBitmap() API

The createImageBitmap() API provides a high-performance, asynchronous mechanism to decode image payloads, and it functions inside Web Workers where DOM elements like HTMLImageElement are unavailable.

async function checkWebPWithImageBitmap() {
  if (typeof createImageBitmap !== 'function') {
    return false;
  }

  // Base64-decoded minimal 1x1 WebP binary blob
  const webpData = Uint8Array.from(
    atob('UklGRiQAAABXRUJQVlA4IBgAAAAwAQCdASoBAAEAAwA0JaQAA3AA/vuUAAA='),
    c => c.charCodeAt(0)
  );
  const blob = new Blob([webpData], { type: 'image/webp' });

  try {
    const bitmap = await createImageBitmap(blob);
    bitmap.close(); // Clean up memory
    return true;
  } catch {
    return false;
  }
}

Using createImageBitmap is the preferred method for performance-sensitive applications, background threads, and Service Workers handling image routing.
