How Shopify Delivers Real-Time WebP Images

Modern e-commerce relies heavily on visual performance, and Shopify optimizes this by automatically serving WebP images to supported desktop and mobile browsers. This article explains how Shopify leverages its content delivery network (CDN), real-time format negotiation via HTTP headers, and responsive image parameters to deliver lightweight WebP assets seamlessly without requiring merchants to manually re-upload or convert their media.

Automatic Format Negotiation via HTTP Headers

Shopify relies on HTTP content negotiation to determine whether to serve a WebP file. When a buyer visits a Shopify storefront—whether on a desktop browser like Chrome or Safari, or on a mobile device—the browser sends a GET request for the image containing an Accept header. If the browser supports modern compression, it includes image/webp in this list. Shopify’s edge servers inspect this header in real time. If image/webp is present, the server provides the WebP version; if not, it serves the original format (such as JPEG or PNG) as a safe fallback.

Real-Time CDN Transformation

Shopify stores the high-resolution master file uploaded by the merchant. Instead of requiring users to upload multiple image variations, Shopify’s CDN—built on global edge infrastructure—processes and converts images on the fly:

  • Edge Caching: When a WebP image is first requested at a specific size, the CDN dynamically converts the source file, compresses it into WebP, and caches it at the edge node closest to the user.
  • Instant Subsequent Delivery: Future requests for the same dimensions and format from other buyers are served instantly from the edge cache, minimizing latency and server load.

Device-Specific Scaling and Responsive Design

Mobile and desktop buyers require different image dimensions to ensure fast load times without sacrificing visual clarity. Shopify facilitates this through liquid filters and native HTML responsive tags:

  • Liquid Filters: Developers use Liquid tags like image_url: width: 800 to define exact pixel requirements in the theme code.
  • Dynamic Query Parameters: When an HTML template renders, it produces URLs appended with query parameters indicating width, height, and cropping.
  • HTML srcset and sizes: Themes dynamically generate srcset attributes. A mobile phone with a high-density screen might request a 600px wide WebP image, while a desktop user receives a 1200px wide WebP image. The CDN evaluates both the sizing parameters and the Accept header simultaneously to deliver the correct WebP asset.

Merchant Simplicity

This entire pipeline functions without merchant intervention. Store owners can upload standard JPEGs, PNGs, or GIFs to the Shopify admin. The platform’s rendering pipeline preserves transparency when converting PNGs to WebP and applies lossy compression to JPEGs, effectively decreasing payload sizes by up to 30% or more while maintaining image quality across all buyer devices.
