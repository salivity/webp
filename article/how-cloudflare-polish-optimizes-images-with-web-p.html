How Cloudflare Polish Optimizes Images with WebP

Cloudflare Polish is a one-click image optimization feature that automatically reduces image file sizes to accelerate website load times. This article explains how Polish detects browser capabilities, converts standard image formats into next-generation WebP files at the network edge, and delivers substantial bandwidth savings without requiring manual code changes or asset management on your origin server.

Understanding Cloudflare Polish

Images frequently account for the majority of a webpage's total payload. Cloudflare Polish resolves this by intercepting requests for images at Cloudflare’s edge servers and applying automated compression before delivering the files to the visitor. Polish operates directly on the edge network, meaning your original images remain untouched on your origin host.

The Mechanism of Automated WebP Conversion

WebP is a modern image format developed by Google that provides superior lossless and lossy compression compared to legacy formats like JPEG and PNG. Polish automates the adoption of WebP through a streamlined, multi-step process:

  1. Browser Support Detection: When a user visits a website, their browser sends an HTTP request containing an Accept header. If the browser supports WebP, it includes image/webp in this header.
  2. Edge Interception: Cloudflare’s edge server inspects this incoming header. If WebP support is indicated and the WebP feature is enabled in Polish, the edge proceeds with transformation.
  3. On-the-Fly Conversion: When an image (JPEG, PNG, or GIF) is first requested, Cloudflare fetches it from the origin server, optimizes it, and converts it into a WebP version.
  4. Edge Caching: The newly generated WebP file is stored in Cloudflare's global cache. Subsequent visitors with WebP-compatible browsers receive this cached version instantly.
  5. Graceful Fallback: If an older client or crawler does not advertise support for WebP, Cloudflare bypasses the WebP file and delivers a standard, optimized version of the original image format instead.

Compression Levels in Polish

Cloudflare Polish offers two primary modes of operation, both of which can be paired with the automated WebP conversion toggle:

  • Lossless: This setting reduces file size without altering any pixel data. It achieves reduction by stripping unnecessary metadata—such as EXIF data, camera profiles, and geolocation tags—while compressing image data strictly without visual degradation.
  • Lossy: This setting applies advanced compression algorithms to remove redundant visual information alongside stripping metadata. It produces substantially smaller files with minimal, typically imperceptible differences in visual quality.

When the "WebP" checkbox is enabled alongside either mode, Polish converts eligible formats into WebP using the chosen compression standard.

Core Benefits for Web Performance

  • Substantial Size Reduction: WebP images are typically 25% to 35% smaller than comparable JPEGs and PNGs at equivalent visual quality, drastically decreasing overall page weight.
  • Improved Core Web Vitals: Delivering smaller image payloads speeds up page rendering, directly improving metrics such as Largest Contentful Paint (LCP).
  • Zero Code Modification: Implementing WebP manually often requires re-encoding entire media libraries and rewriting HTML to include HTML5 <picture> tags with multiple source fallbacks. Polish handles format negotiation and delivery entirely at the edge, requiring no HTML or code changes.
  • Reduced Origin Bandwidth: Because Cloudflare caches and serves the optimized WebP assets directly from its edge data centers, requests to your origin server decrease significantly.
