How Subtract Green Transform Improves WebP Entropy

The subtract green transform in WebP lossless compression is a decorrelation technique that drastically reduces cross-channel redundancy in RGB images. By subtracting the green channel's values from both the red and blue channels, it shifts the statistical distribution of color data toward zero. This concentration of values reduces the dynamic range and overall Shannon entropy of the image data, enabling subsequent entropy coding stages—such as LZ77 dictionary coding and Huffman coding—to compress the file significantly more efficiently.

Eliminating Inter-Channel Correlation

Natural images exhibit a high degree of correlation between their color channels. Because the human visual system is most sensitive to green wavelengths, cameras and image sensors capture the majority of luminance and fine structural detail within the green channel. Consequently, variations in brightness or texture usually manifest simultaneously across red, green, and blue. Storing raw RGB values independently wastes space by encoding this shared structural information three separate times.

The Mathematics of the Transform

To remove this redundancy, WebP applies a reversible, lossless transformation before running its entropy coding pipeline. The operation computes new red (\(R'\)) and blue (\(B'\)) values by subtracting the green value (\(G\)) modulo 256:

  • \(R' = (R - G) \pmod{256}\)
  • \(G' = G\)
  • \(B' = (B - G) \pmod{256}\)

Because the transformation is modular arithmetic, it is completely reversible on decoding:

  • \(R = (R' + G) \pmod{256}\)
  • \(B = (B' + G) \pmod{256}\)

Impact on Probability Distribution and Entropy

Entropy coding algorithms compress data by assigning shorter bit-lengths to symbols that appear frequently and longer bit-lengths to rare symbols. The fundamental limit of this compression is defined by Shannon entropy: a flatter, uniform distribution of values has high entropy (difficult to compress), while a distribution with sharp peaks has low entropy (easy to compress).

In standard RGB images, red and blue values are spread across the full 0–255 range. When green is subtracted, the difference between correlated channels is usually very small. As a result, the values of \(R'\) and \(B'\) cluster heavily around zero (or 255 due to wrap-around). This collapse of the probability distribution drastically lowers the entropy of the red and blue channels.

Boosting LZ77 and Huffman Coding Performance

WebP lossless compression relies on a combination of LZ77 sliding-dictionary matching, prefix (Huffman) coding, and a local color cache. The subtract green transform directly benefits these mechanisms:

  1. Enhanced LZ77 String Matches: Because pixel differences become uniform across flat or textured areas, repetitive byte sequences occur much more frequently. The LZ77 algorithm can locate longer, more frequent backward references across image scanlines.
  2. Optimal Prefix Coding: Canonical Huffman codes yield the shortest prefixes for the most common symbols. With \(R'\) and \(B'\) values heavily biased toward zero, the entropy encoder can assign extremely short bit-codes to the dominant differences, substantially shrinking the final bitstream.
