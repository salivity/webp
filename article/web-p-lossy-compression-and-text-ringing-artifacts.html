WebP Lossy Compression and Text Ringing Artifacts

WebP lossy compression can indeed cause visible ringing artifacts around sharp text edges. Because lossy WebP relies on transform coding algorithms originally derived from the VP8 video codec, it struggles with high-contrast, high-frequency transitions such as sharp text boundaries. Discarding fine high-frequency details during compression produces characteristic "halos" or smudges around the letters, which can severely degrade legibility.

Why Ringing Artifacts Occur in WebP

WebP's lossy compression is based on the VP8 intra-frame prediction method, which subdivides images into blocks (typically 4x4 or 16x16 pixels) and applies a Discrete Cosine Transform (DCT) variant to represent spatial data as frequency coefficients.

Text consists of hard, abrupt transitions between contrasting colors—such as black text on a white background. Mathematically, representing these sharp, instantaneous step changes requires an infinite sum of high-frequency sine waves.

When an image is compressed using lossy WebP:

  1. Quantization Discards High Frequencies: The compression engine quantizes (rounds down or eliminates) the highest-frequency coefficients to reduce file size.
  2. Gibbs Phenomenon: Reconstructing the sharp edge from the remaining, truncated frequency coefficients causes oscillations in pixel values adjacent to the boundary.
  3. Visible Ringing: These mathematical oscillations manifest visually as faint, wavy lines, halos, or blurry speckles outlining the typography.

Chroma Subsampling and Text Degradation

By default, lossy WebP uses 4:2:0 chroma subsampling. This process cuts the resolution of the color information in half horizontally and vertically. If text includes colored fonts or rests on a colored background, chroma subsampling smears the color boundaries before transform compression even occurs, further amplifying edge fuzziness and color bleeding alongside ringing artifacts.

How to Prevent Ringing Artifacts Around Text

To maintain crisp text without artifacting, consider the following approaches:

  • Switch to WebP Lossless: WebP includes a dedicated lossless mode that does not discard spatial frequency data. It relies on advanced spatial transformations and entropy coding, keeping text edges pixel-perfect while still achieving superior compression compared to PNG.
  • Increase Quality Parameters: Raising the lossy quality setting (typically above 85 or 90) reduces quantization aggressiveness, preserving more high frequencies and minimizing halo effects at the cost of larger file sizes.
  • Separate Text from Imagery: Whenever possible, render text dynamically using modern web fonts, HTML, and CSS overlays over background images, or deliver text-heavy diagrams as scalable vector graphics (SVG).
