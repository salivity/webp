Tools to Strip Metadata from WebP Images

Production WebP files often carry extraneous metadata chunks—such as EXIF camera data, XMP management data, and embedded ICC color profiles—that inflate asset payloads without contributing to image rendering. Stripping this non-visual data optimizes delivery speeds and minimizes bandwidth consumption in web environments. The following tools represent the most reliable and efficient methods for removing these chunks in production workflows.

1. webpmux (libwebp)

Maintained directly by Google as part of the official libwebp repository, webpmux is the definitive low-level utility for reading, adding, and stripping WebP chunks. Unlike general image transcoders, it operates directly on the container structure without re-encoding pixel data, ensuring 100% fidelity with zero quality degradation.

To strip color profiles and metadata:

webpmux -strip icc -strip exif -strip xmp input.webp -o output.webp

Because it bypasses the pixel decode-encode pipeline, webpmux executes almost instantaneously, making it the ideal candidate for continuous integration (CI) and build-time asset pipelines.

2. cwebp (libwebp)

If WebP files are generated from source formats (such as JPEG or PNG) during production builds, metadata should be stripped at the point of encoding using cwebp. By default, cwebp excludes most metadata unless explicitly commanded to retain it, but you can explicitly enforce this behavior.

cwebp -metadata none input.png -o output.webp

The -metadata none flag guarantees that no EXIF, XMP, or ICC chunks are written into the final .webp file.

3. ExifTool

Phil Harvey's ExifTool is an industry-standard Perl utility for reading, writing, and manipulating metadata across hundreds of file formats, including WebP. It can purge all metadata chunks in-place while keeping the core RIFF container and VP8/VP8L bitstream intact.

To strip all metadata from a WebP image:

exiftool -all= -overwrite_original image.webp

To batch-process an entire directory:

exiftool -all= -r -ext webp -overwrite_original ./images/

4. ImageMagick

ImageMagick provides the -strip operator, which purges all profiles, comments, and ancillary metadata segments. This approach fits well into existing automated image delivery microservices.

Using magick (ImageMagick 7):

magick input.webp -strip output.webp

To modify files in place across an entire directory:

mogrify -strip *.webp

Note: Depending on configuration and flags, standard ImageMagick conversions may re-encode the pixel stream. Ensure that compression flags (such as -quality 100 or -define webp:lossless=true) match your asset requirements to prevent generational compression loss.

5. libvips

libvips is an image-processing library optimized for high throughput and low memory footprint, outperforming traditional tools in real-time server environments. It natively supports stripping metadata during operations via CLI or bindings (such as sharp for Node.js or pyvips for Python).

Using the CLI:

vips webpsave input.webp output.webp --strip

Using Node.js (sharp):

const sharp = require('sharp');

await sharp('input.webp')
  .webp({ effort: 6 })
  .toFile('output.webp'); // sharp automatically strips metadata unless .withMetadata() is called
