How PageSpeed Insights Audits WebP Images

Google PageSpeed Insights (PSI) evaluates WebP adoption by auditing image payloads to identify opportunities where modern compression can reduce page load times. Powered by the Lighthouse analysis engine, the tool inspects every raster image rendered during a page load, estimates the potential byte savings achievable by converting traditional formats to next-generation formats like WebP or AVIF, and flags underperforming assets that negatively impact performance scores and Core Web Vitals.

The evaluation takes place primarily under the "Serve images in next-gen formats" audit. During the audit process, Lighthouse collects all network requests for image assets, specifically targeting traditional formats such as JPEG, PNG, and GIF. The engine performs an automated conversion of these assets to WebP behind the scenes using fixed compression quality settings to determine an optimized target file size.

To prevent false positives and unnecessary warnings, PSI applies a savings threshold. The audit only flags an image if converting it to WebP yields a minimum potential saving of 8 KiB or more. If the estimated savings across all page images exceed this threshold, PSI lists the offending image URLs along with their current transfer sizes and the estimated byte savings.

PSI's analysis relies on the actual binary data and the Content-Type HTTP response header, not just the file extension in the URL. If a server uses dynamic content negotiation via the Accept header to serve WebP data under a .jpg extension, PSI correctly identifies the format as WebP and passes the audit, provided the compression is efficient.

Images audited under this rule directly influence Core Web Vitals, particularly Largest Contentful Paint (LCP). If the primary LCP element is a high-resolution hero image served in an unoptimized legacy format, the failure to adopt WebP will increase download latency, directly lowering both the LCP score and the overall PageSpeed performance rating.
