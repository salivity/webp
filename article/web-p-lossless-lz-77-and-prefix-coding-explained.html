WebP Lossless LZ77 and Prefix Coding Explained

WebP lossless format relies on a combination of LZ77 backward referencing, color caching, and canonical prefix (Huffman) coding to compress image data without losing fidelity. The compression pipeline first transforms the image data into an optimized intermediate state, then uses an LZ77 variant to detect repeating spatial patterns across pixel channels, and finally encodes the resulting symbols, lengths, and distances using specialized, spatially adaptive prefix-free codes.

The LZ77 Backward Referencing Mechanism

In WebP lossless mode, LZ77 operates on a stream of 32-bit ARGB pixels rather than a raw byte stream. The algorithm scans previously processed pixels in the image to locate matching sequences, replacing repetitive data with backward references defined by two values: length and distance.

  • Length: Indicates the number of pixels to copy sequentially. WebP supports match lengths ranging from 1 to 4096 pixels.
  • Distance: Specifies how far back in the stream the match began. Because 2D images have high spatial correlation both horizontally and vertically, WebP uses a specialized 2D-to-1D mapping for distance codes. Distances corresponding to immediate 2D neighbors (such as the pixel directly above, to the upper-left, or to the upper-right) are assigned low, easily compressible distance values instead of purely linear scanline offsets.

When no matching sequence of sufficient length is found, the encoder outputs pixel values as literals.

Unified Symbol Alphabet

WebP lossless consolidates literals, backward reference lengths, and color cache references into a single alphabet to optimize entropy coding. The pipeline groups image data into five separate symbol spaces:

  1. Green channel / Literals / Lengths / Cache: This primary channel carries green color literals (0–255), LZ77 copy lengths (256–279, followed by extra bits to express lengths up to 4096), and color cache references.
  2. Red channel: Carries red literals (0–255).
  3. Blue channel: Carries blue literals (0–255).
  4. Alpha channel: Carries transparency literals (0–255).
  5. Distance: Contains the prefix codes for backward reference distances (0–39), which are followed by extra literal bits to specify the exact offset.

Combining the green channel literals and LZ77 match lengths into a single prefix tree avoids the overhead of explicitly signaling whether the current token is a literal or a backward reference.

Prefix-Free (Canonical Huffman) Coding

All five symbol groups are encoded using canonical prefix-free codes. A prefix-free code guarantees that no code is a prefix of another, allowing the decoder to parse the bitstream sequentially without delimiters.

  • Code Construction: Symbol frequencies determine the bit lengths of the codes. Canonical codes are generated directly from these lengths, ensuring that the decoder only needs to know the code lengths rather than the full tree topology.
  • Header Compression: The bit lengths of the prefix codes are themselves compressed using an internal prefix-free code (similar to the DEFLATE standard). The bit-length alphabet consists of codes representing lengths 0–15, as well as repeat codes for repeating zeros or previous values.

Spatially Adaptive Meta-Prefix Codes

Entropy varies across different regions of an image. To account for this, WebP lossless avoids using a single global set of prefix codes. Instead, it supports spatially localized entropy coding:

  • Grid Partitioning: The image is partitioned into non-overlapping blocks (typically sized as powers of two, such as 16×16 pixels).
  • Entropy Groups: Multiple sets of prefix codes (each set containing the five canonical trees) are generated for different texture types or color profiles.
  • Meta-Code Array: A small, low-resolution index map assigns each block in the image grid to a specific entropy group.

During decoding, the engine consults the meta-code array to identify which set of prefix-free trees to use for the current block, maximizing compression efficiency across both uniform and complex areas of the image.
