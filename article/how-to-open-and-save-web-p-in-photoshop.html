How to Open and Save WebP in Photoshop

Adobe Photoshop includes native support for the WebP image format, eliminating the need for third-party plug-ins or manual add-ons. Starting with Photoshop version 23.2, users can directly open, edit, and export WebP images within their standard workflows. This native integration supports both lossy and lossless compression, transparency channels, and embedded metadata, making WebP as seamless to use as standard formats like JPEG and PNG.

Native Integration Overview

Prior to Photoshop 23.2, working with WebP required manually installing Google’s WebPShop plug-in into the application's directory. With native integration, the WebP codec is built directly into Photoshop’s core engine across both Windows and macOS platforms. This allows the software to decode and encode .webp files instantly, streamlining web asset production without requiring external utilities or conversion tools.

Importing WebP Files

To open a WebP file in Photoshop, use any standard import method:

  • Direct Open: Navigate to File > Open, select the .webp file, and click Open.
  • Drag-and-Drop: Drag a WebP image from your file manager directly onto the Photoshop workspace.
  • Smart Objects: Insert a WebP file into an existing document via File > Place Embedded or File > Place Linked.

Photoshop automatically decodes the image data, loading it with all color information and preserving transparency layers where applicable.

Exporting and Saving as WebP

Photoshop handles WebP creation primarily through the Save a Copy and Save As workflows. Because WebP often serves as a compressed delivery format rather than a layered working file, Photoshop directs you to save a copy if your working canvas contains multiple layers, masks, or adjustment layers.

To export your work in the WebP format:

  1. Go to File > Save a Copy (or File > Save As if the document is flattened).
  2. Select WebP from the Format dropdown menu.
  3. Choose a destination, name your file, and click Save.

WebP Specification Settings

Once you trigger the save command, Photoshop displays the native WebP options dialog box, allowing you to configure the output settings:

  • Compression Type: Choose between Lossy and Lossless. Lossy compression yields the smallest file sizes by selectively discarding data, while lossless retains exact pixel-level accuracy.
  • Quality Slider: In Lossy mode, adjust quality from 0 (maximum compression, lower quality) to 100 (minimal compression, highest quality).
  • Alpha Channel: If your document contains transparent areas, check this option to retain the transparent background.
  • Metadata: Choose whether to include or strip embedded XMP and EXIF metadata to optimize the final file size for the web.

Automation and Batch Processing

Because WebP is a native format in Photoshop, it integrates directly into automated pipelines. You can record custom Actions using the WebP export workflow and apply them across large batches of images via File > Scripts > Image Processor or File > Automate > Batch, significantly speeding up image optimization workflows for web development.
