Google libwebp Library Software License

This article provides an overview of the specific software licensing governing the official Google libwebp source repository. It covers the core license type, the included patent grants, and the practical implications for developers incorporating the WebP image processing library into open-source or commercial applications.

The Core License: BSD 3-Clause

The official Google libwebp repository is governed primarily by the BSD 3-Clause License (also known as the "Modified BSD License" or "New BSD License"). This license is explicitly detailed in the COPYING file located in the root directory of the official libwebp source tree.

Under the terms of the BSD 3-Clause License, redistribution and use in source and binary forms, with or without modification, are permitted provided that the following conditions are met:

  1. Retention of Copyright Notices: Redistributions of source code must retain the original copyright notice, the list of conditions, and the standard disclaimer.
  2. Reproduction in Documentation: Redistributions in binary form must reproduce the original copyright notice, the list of conditions, and the disclaimer in the documentation and/or other materials provided with the distribution.
  3. Restriction on Endorsements: Neither the name of Google nor the names of its contributors may be used to endorse or promote products derived from the software without specific prior written permission.

Additional Patent Grant

In addition to the standard BSD terms, the official libwebp repository includes a separate PATENTS file. This file grants an additional patent license directly from Google:

  • Google grants a perpetual, worldwide, non-exclusive, no-charge, royalty-free patent license for claims owned or controlled by Google that are necessarily infringed by the implementation of libwebp.
  • This patent grant includes a standard defensive termination clause: if any entity initiates patent litigation against Google or other contributors alleging that libwebp constitutes patent infringement, any patent rights granted to that entity for libwebp terminate automatically.

Commercial and Open-Source Implications

Because the BSD 3-Clause License is a permissive free software license:

  • Commercial Use: Organizations can use, modify, and distribute libwebp inside proprietary, closed-source commercial software without being required to release their own source code.
  • GPL Compatibility: The 3-Clause BSD License is recognized by the Free Software Foundation as compatible with the GNU General Public License (GPL), meaning libwebp can be freely combined with GPL-licensed software.
