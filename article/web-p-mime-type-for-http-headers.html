WebP MIME Type for HTTP Headers

This guide covers the official MIME type assigned to WebP images, explains its critical role in standard HTTP request and response headers, and outlines how to configure popular web servers to serve WebP files correctly to ensure seamless browser rendering.

The standard MIME type assigned to WebP images by the Internet Assigned Numbers Authority (IANA) is image/webp.

When a web server delivers a WebP image to a client, it must include this identifier in the Content-Type HTTP response header:

Content-Type: image/webp

Why the WebP MIME Type Matters

Modern web browsers rely on the Content-Type header rather than the file extension (.webp) to determine how to process and render a resource. If a server sends the wrong MIME type (such as application/octet-stream or text/plain), the browser may fail to display the image inline and instead attempt to download it as a generic file or report a broken resource.

Additionally, during content negotiation, browsers that support WebP signal this capability to the server using the Accept request header:

Accept: image/avif,image/webp,image/apng,image/svg+xml,image/*,*/*;q=0.8

This allows servers and Content Delivery Networks (CDNs) to dynamically serve a WebP version of an image only when the client explicitly supports image/webp.

How to Configure Common Web Servers

Most modern web servers include native support for WebP, but custom or older environments may require explicit configuration.

Apache

Add the following directive to your httpd.conf or .htaccess file:

AddType image/webp .webp

Nginx

Ensure the mapping exists within your /etc/nginx/mime.types file inside the types block:

types {
    image/webp webp;
}

Microsoft IIS

Add the MIME mapping to your web.config file inside the <system.webServer> section:

<staticContent>
    <mimeMap fileExtension=".webp" mimeType="image/webp" />
</staticContent>

Configuring image/webp correctly ensures optimal compression delivery, fast load times, and uninterrupted cross-browser rendering for all WebP assets.
