Nuxt Image Default WebP Optimization Settings

This article provides a direct overview of the default parameters Nuxt.js applies when generating and serving WebP images. In the Nuxt ecosystem, image optimization is handled by the official @nuxt/image module, which relies on IPX (an image processing middleware) and the Sharp image processing library by default. Below are the specific default parameters applied during WebP generation, along with details on how to configure them.

Default Processing Engine

Nuxt does not have a proprietary image encoder built directly into its framework core. Instead, it delegates image transformation to the @nuxt/image module. By default, it uses IPX, an open-source image proxy powered by Sharp. Therefore, the default generation settings for WebP images inherit directly from Sharp’s default WebP encoding configuration.

Default WebP Parameters

When converting images to WebP without manual overrides, Nuxt Image and IPX apply the following base parameters:

  • Quality (quality): Defaults to 80. Sharp sets WebP quality between 1 and 100, targeting an optimal balance between visual fidelity and payload size.
  • Compression Mode (lossless): Defaults to false. Images undergo lossy compression unless the original input is explicitly designated as lossless or specified via attributes.
  • CPU Effort (effort): Defaults to 4 (on a scale from 0 to 6). This controls the trade-off between encoding speed and compression ratio. A value of 4 ensures fast server-side responses while maintaining strong compression.
  • Chroma Subsampling: Defaults to 4:2:0. High-frequency color data is reduced to minimize file size, which is standard for web delivery.
  • Near-Lossless (nearLossless): Defaults to false.
  • Smart Subsampling (smartSubsample): Defaults to false.

Default Responsive and Sizing Settings

When generating responsive WebP images using <NuxtImg> or <NuxtPicture>, Nuxt also applies standardized dimension constraints:

  • Pixel Densities (densities): Defaults to [1, 2]. When generating source sets (srcset), Nuxt automatically renders 1x standard and 2x high-DPI (Retina) versions.
  • Default Screen Breakpoints: If unspecified, predefined breakpoints determine generated widths:
    • xs: 320px
    • sm: 640px
    • md: 768px
    • lg: 1024px
    • xl: 1280px
    • xxl: 1536px
    • 2xl: 1536px

How to Override Defaults

Default WebP settings can be adjusted globally in nuxt.config.ts or per component:

Global Configuration

export default defineNuxtConfig({
  modules: ['@nuxt/image'],
  image: {
    format: ['webp'],
    quality: 85,
    screens: {
      sm: 640,
      md: 768,
      lg: 1024
    }
  }
})

Per-Component Override

<NuxtImg 
  src="/example.jpg" 
  format="webp" 
  quality="90" 
  width="800" 
  height="600" 
/>
