Extract Animated WebP Frames Using Python Pillow

Extracting frames from animated WebP files using Python's Pillow library relies on internal frame-seeking mechanisms and sequence iterators. This guide explains how Pillow parses animated WebP containers, navigates through individual frames sequentially using the seek() method or the ImageSequence module, handles alpha transparency and frame state, and exports those frames to standalone image files.

Opening Animated WebP Files

When you open an animated WebP file using Image.open(), Pillow initializes the image at the first frame (frame 0) without loading the entire animation into memory. Pillow identifies multi-frame capabilities through the is_animated attribute and stores the total number of frames in the n_frames attribute.

from PIL import Image

image = Image.open("animation.webp")

print(f"Is animated: {getattr(image, 'is_animated', False)}")
print(f"Total frames: {getattr(image, 'n_frames', 1)}")

Navigating Frames with seek() and tell()

Pillow maintains an internal frame pointer. You can inspect the current frame index using tell() and move to a specific frame using seek(frame_index).

When moving from one frame to another, Pillow relies on libwebp to decode the frame data. If an invalid frame index is requested, Pillow raises an EOFError.

# Jump to the 5th frame
image.seek(4)
print(f"Current frame: {image.tell()}")

Idiomatic Extraction with ImageSequence

The cleanest way to process every frame in an animated WebP is using Pillow's ImageSequence.Iterator. It wraps the seek() mechanism in an iterable interface.

When extracting frames, you must call .copy() or convert the frame mode (such as to RGBA). Because Pillow mutates the underlying image object as it iterates, failing to make a copy will result in references pointing to the final state of the iterator rather than distinct frames.

from PIL import Image, ImageSequence

with Image.open("animation.webp") as im:
    for index, frame in enumerate(ImageSequence.Iterator(im)):
        # Create an independent copy to preserve frame data
        extracted_frame = frame.copy()
        extracted_frame.save(f"frame_{index:03d}.png", format="PNG")

Handling Transparency and Disposal

Animated WebP images often use frame disposal and blending techniques to optimize file size, storing only the rectangular sub-region that changes between frames.

Pillow's WebP plugin automatically handles background disposal and canvas reconstruction as it iterates sequentially. When jumping randomly using seek(), Pillow renders intermediate frames in the background to ensure the target frame is visually complete and composite-accurate. To retain transparency during export, ensure the destination format supports an alpha channel (such as PNG or WebP) and verify the image is in RGBA mode.

Extracting Frame Metadata

Individual frames inside an animated WebP can carry metadata, such as display duration. Pillow exposes this through the info dictionary:

duration = frame.info.get("duration", 100)  # Duration in milliseconds

This metadata allows you to retain timing information if you intend to reassemble the extracted frames into another format or sequence.
