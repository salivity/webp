Lossy WebP for Scientific Floating-Point Arrays

Using lossy WebP compression to store floating-point scientific pixel arrays introduces severe data corruption, precision loss, and mathematical artifacts. Scientific arrays typically require high-precision continuous values (such as 32-bit or 64-bit floats) to represent physical quantities accurately. Because lossy WebP is designed specifically for standard 8-bit photographic imagery optimized for human perception, converting scientific arrays into this format fundamentally alters numerical values, destroys spatial relationships, and invalidates quantitative analysis.

Bit-Depth Reduction and Quantization

Standard lossy WebP relies on the VP8 video codec profile, which natively operates on 8-bit unsigned integers per channel (0 to 255). Scientific float data (FP32 or FP64) spans vast dynamic ranges, including fractional, negative, and extreme values. To store floats in lossy WebP, the data must first be normalized and quantized to fit an 8-bit integer space. This step alone collapses continuous measurements into just 256 discrete levels, instantly eliminating precision and truncating low-amplitude signals that may contain vital physical measurements.

Chroma Subsampling Destroys Channel Independence

Lossy WebP encodes images using the YUV 4:2:0 color space, which halves the spatial resolution of the color (U and V) channels relative to the luminance (Y) channel. In scientific computing, multi-channel arrays represent independent variables (such as velocity components, multi-spectral bands, or electromagnetic field tensors) rather than perceptual color. Storing these channels in a YUV 4:2:0 container averages adjacent data points across 2x2 pixel neighborhoods, irreversibly blending independent scientific metrics and corrupting spatial fidelity.

Frequency-Domain Artifacts and Block Boundaries

Lossy WebP relies on the Discrete Cosine Transform (DCT) and spatial prediction to discard high-frequency data that the human visual system cannot easily distinguish. In scientific arrays, high-frequency variations represent real physical phenomena, such as steep pressure gradients, shock waves, particle boundaries, or localized sensor responses. The DCT compression introduces characteristic ringing artifacts, blurred boundaries, and blocking artifacts at 4x4 and 16x16 macroblock seams, generating false gradients and distorting downstream derivative or differential calculations.

Inability to Handle Non-Finite and Out-of-Bounds Values

Scientific computing frequently generates special floating-point values, including negative numbers, zero-crossings, NaN (Not a Number), and positive or negative infinity (+/-Inf). Lossy WebP has no mechanism to represent non-finite numbers or arbitrary numerical ranges. Attempting to encode these values forces arbitrary clamping, zero-filling, or manual packing strategies that risk silent data failure during decoding.

Non-Deterministic Precision Degradation

Unlike specialized lossy scientific compressors (such as ZFP or SZ), which allow researchers to define explicit error bounds (such as absolute error tolerance or fixed peak signal-to-noise ratios), lossy WebP uses perceptual quality metrics. A lossy WebP quality factor (e.g., 75 or 85) does not translate to a consistent numerical error bound across an array. As a result, the error margin introduced by compression varies unpredictably across different regions of the dataset.

For scientific arrays requiring compression, native scientific data containers such as HDF5, Zarr, NetCDF, or multi-page floating-point TIFF coupled with precision-preserving codecs (such as Blosc, Zstandard, or ZFP) should be used instead of perceptual visual formats like lossy WebP.
