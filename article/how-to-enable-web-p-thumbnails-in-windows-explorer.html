How to Enable WebP Thumbnails in Windows Explorer

Windows File Explorer often lacks out-of-the-box thumbnail previews for Google's WebP image format, displaying generic icons instead of image contents. This guide outlines the top shell extensions and Windows Imaging Component (WIC) codecs available to enable native WebP thumbnail previews seamlessly inside Windows 10 and Windows 11.

1. WebP Image Extensions (Microsoft Store)

The official and cleanest solution for modern Windows systems is the WebP Image Extensions package published by Microsoft on the Microsoft Store.

  • How it works: It installs a system-wide Windows Imaging Component (WIC) decoder.
  • Benefits: Integrates natively with Windows 10 and 11, requires zero configuration, updates automatically via the Microsoft Store, and enables previews in both File Explorer and the default Photos app.

2. Icaros

Icaros is a lightweight, highly customizable Windows shell extension powered by FFmpeg media decoders. While primarily known for video thumbnails, it provides robust support for image formats, including WebP.

  • How it works: Replaces default Explorer thumbnail handlers with high-speed FFmpeg-based generation.
  • Benefits: Flawless compatibility with 64-bit Windows installations, customizable thumbnail margins/borders, and support for almost every media format alongside WebP.
  • Setup: Open the Icaros configuration tool, ensure the .webp extension is included in the filetypes list, and click Activate.

3. SageThumbs

SageThumbs is a powerful Windows shell extension that allows Windows Explorer to generate thumbnails for more than 200 image formats using GFL library algorithms.

  • How it works: Hooks directly into Explorer's context menu and preview pipeline.
  • Benefits: Displays quick image dimension/color tooltips on mouse hover, provides a right-click context menu to instantly convert WebP files to JPG/PNG, and handles high-resolution WebP files reliably.
  • Setup: Install the extension, open SageThumbs Options, and confirm that WebP support is enabled.

4. Google WebP Codec for Windows

Google previously offered an official WebP Codec for Windows installer, which implements the WIC interface to render thumbnails and full previews.

  • How it works: Registers a native 32-bit and 64-bit WIC decoder directly into the Windows Registry.
  • Benefits: Official Google implementation without extra menus or third-party wrappers.
  • Note: Google has discontinued active development of this installer in favor of platform-level integrations, making Microsoft's Store extension or Icaros a better choice for modern Windows 11 machines.

Troubleshooting Missing Thumbnails

If WebP thumbnails do not appear immediately after installing a shell extension:

  1. Open the Run dialog (Win + R), type cleanmgr, and run Disk Cleanup.
  2. Select your system drive, check Thumbnails, and click OK to clear the thumbnail cache.
  3. Restart Windows Explorer via the Task Manager to force Windows to rebuild thumbnails using the newly installed extension.
