WebP CLI Settings for Crisp Pixel Art

Converting pixel art to the WebP format can inadvertently introduce blur, edge smearing, and color bleeding if default lossy compression routines are applied. This guide provides the exact command-line parameters required using Google's official cwebp tool to ensure your sprites and pixel artwork retain perfectly sharp edges, accurate color boundaries, and zero artifacting.

The Essential Command

To preserve the 1:1 crispness of pixel art, you must encode the image using true lossless mode and preserve transparent pixel color values. Use the following command:

cwebp -lossless -exact input.png -o output.webp

Breakdown of Key Settings

  • -lossless: This is the most critical flag. By default, cwebp applies lossy compression, which relies on discrete cosine transforms and spatial predictions that smooth out hard edges. The -lossless flag completely bypasses these transforms, guaranteeing that every pixel coordinate and color value is retained exactly as in the source file.
  • -exact: Pixel art often uses transparency for sprites. By default, cwebp alters RGB data in fully transparent areas to improve compression. Adding -exact preserves the invisible RGB values, preventing outline discoloration, dark fringing, or alpha-bleed when the asset is rendered against varying backgrounds in game engines or browsers.
  • -z 9 (Optional, Compression Level): Add -z 9 to apply the slowest, most aggressive lossless compression. This does not degrade visual quality; it only expends more CPU time to minimize the final file size.

Avoid Detrimental Flags

Do not use quality flags (-q) without -lossless. In lossy mode, even -q 100 introduces subtle edge-smoothing filters. Similarly, avoid deblocking filters (-f), strength filters, or auto-scaling arguments during encoding, as these algorithms inherently resample and blur high-contrast pixel boundaries.

Presentation on the Web

Even a perfectly encoded WebP will appear blurry if scaled up in modern web browsers due to default bilinear interpolation. To maintain crispness at enlarged display sizes, pair your WebP asset with the following CSS property:

img.pixel-art {
  image-rendering: pixelated;
}
