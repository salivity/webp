Can WebP Support Display P3 and Adobe RGB Profiles?

WebP fully supports embedded color profiles, allowing images to accurately display wide color gamuts such as Display P3, Adobe RGB, and ProPhoto RGB. Through the use of standard International Color Consortium (ICC) profiles embedded within the WebP container format, modern browsers and operating systems can correctly read and render wide-gamut color data. This guide explains how WebP color management works, browser compatibility, and how to embed these profiles effectively.

How WebP Stores Color Profiles

The WebP specification is built on the Resource Interchange File Format (RIFF). While simple WebP images consist only of the core bitstream, the Extended WebP file format (indicated by a VP8X header chunk) supports optional metadata chunks.

Embedded color profiles are stored inside a dedicated ICCP (ICC profile) chunk. This chunk carries the raw, standard ICC profile payload, identical to how ICC profiles are embedded in JPEG, PNG, or TIFF files. Because the specification relies on standard ICC data rather than a proprietary color system, any valid color profile—including Display P3 and Adobe RGB (1998)—can be encapsulated.

Color Gamut Support: Display P3 and Adobe RGB

When an image is exported to WebP with an embedded Display P3 or Adobe RGB profile:

  1. Color Data Preservation: The pixel values are mapped according to the wider gamut rather than being clipped or compressed down to standard sRGB.
  2. Display Translation: When rendered on a wide-gamut display (such as modern Apple Retina screens or wide-gamut desktop monitors), color-managed software translates the embedded color coordinates to match the screen's physical capabilities. This produces richer reds, deeper greens, and overall more vibrant colors without banding or clipping.
  3. Fallback Handling: If viewed on a standard sRGB monitor, color-managed software automatically maps the wide-gamut colors to the closest reproducible sRGB equivalents.

Browser and Platform Support

Support for color profiles in WebP is broad across all modern platforms:

  • Web Browsers: Google Chrome, Apple Safari, Mozilla Firefox, and Microsoft Edge all respect embedded ICC profiles in WebP images and apply native color management.
  • Operating Systems: macOS, iOS, Windows, and Android handle system-level color management, allowing applications utilizing system graphics APIs to read the WebP ICCP chunk correctly.

Impact on File Size

Embedding an ICC profile increases the final file size of a WebP image:

  • Standard Profiles: Full-featured ICC profiles can add anywhere from 3 KB to over 50 KB of overhead to the file.
  • Compact/Matrix Profiles: For web optimization, it is recommended to use minimal matrix-based profiles (often under 1 KB) to define Display P3 or Adobe RGB. This preserves wide-gamut fidelity while maintaining the bandwidth advantages of the WebP format.

How to Preserve Profiles During Export

To ensure the color profile is included when generating WebP files:

  • Google's cwebp CLI: Use the -metadata icc or -metadata all flag. Without this flag, cwebp strips all metadata by default, converting the image to untagged data that browsers will assume is sRGB.
  • Image Editing Software: In applications like Adobe Photoshop, ensure "Embed Color Profile" is checked in the export or save dialogue.
  • ImageMagick: Use -define webp:include-metadata=icc during conversion to prevent profile stripping.
