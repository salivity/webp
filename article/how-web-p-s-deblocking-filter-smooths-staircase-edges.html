How WebP's Deblocking Filter Smooths Staircase Edges

WebP’s lossy compression relies on transform-based block coding, which can introduce distinct "staircase" or stepping artifacts along diagonal borders and block boundaries at lower bitrates. To counteract this degradation, WebP employs an in-loop, content-aware smart deblocking filter that identifies these artificial boundaries and selectively applies targeted smoothing. By analyzing local pixel variance, evaluating quantization parameters, and adjusting pixel gradients perpendicular to block edges, the filter successfully smooths staircase discontinuities while preserving legitimate high-contrast details.

The Origin of Staircase Boundary Edges

Lossy WebP encodes images using macroblocks divided into smaller 4x4 sub-blocks, which are then transformed and quantized. When an image contains diagonal lines, curved contours, or soft gradients, dividing them into a rigid square grid creates discontinuities. Quantization truncates high-frequency coefficients independently in adjacent blocks. Consequently, a smooth diagonal line breaks into discrete, step-like segments along block borders—commonly referred to as staircase boundary edges.

Content-Adaptive Boundary Evaluation

The smart deblocking filter does not apply uniform blurring across the image grid. Instead, it inspects adjacent pixels spanning every horizontal and vertical 4x4 block interface (typically evaluating boundary pixels labeled \(p_1, p_0\) on one side and \(q_0, q_1\) on the other).

The filter checks whether the gradient between \(p_0\) and \(q_0\) represents an artificial block discontinuity or an intended visual edge. This decision relies on two key thresholds:

  • Filter Limit (\(\alpha\)): Determines the maximum permissible difference between neighboring boundary pixels before the algorithm classifies the transition as an intentional edge.
  • Inner Flatness Threshold (\(\beta\)): Measures the consistency of pixels on either side of the boundary (\(|p_1 - p_0|\) and \(|q_1 - q_0|\)). If the interior of both blocks is relatively flat, any sharp step at the boundary is classified as an artifact rather than image detail.

Both thresholds scale dynamically with the quantization parameter (QP). At higher compression ratios, the filter broadens its tolerances to catch pronounced staircase stepping.

Normal vs. Complex Filtering Modes

WebP employs two main filter strengths depending on the severity of the artifact and user encoding settings:

  1. Simple Filtering: Primarily targets flat areas and simple luminance boundaries by adjusting only the immediate boundary pixels (\(p_0\) and \(q_0\)).
  2. Complex Filtering: Engages when the algorithm detects continuous gradients or subtle diagonal edges affected by staircase distortion. In this mode, the filter extends up to two or three pixels deep into each block (\(p_2, p_1, p_0\) and \(q_0, q_1, q_2\)). By calculating higher-order differences, the complex mode distributes a linear smoothing response across the entire boundary zone, converting harsh 90-degree step artifacts into fluid, continuous transitions.

Preserving Sharp Details with Value Clipping

To prevent the smoothing process from degrading sharp, legitimate line art or natural high-contrast boundaries, the deblocking algorithm uses a strict clipping mechanism. When correcting boundary values, the calculated adjustment delta is clamped to an upper limit governed by the QP. If an edge transition exceeds the filter’s thresholds, filtering is bypassed entirely. This conditional smoothing eliminates the step-like distortion of staircase edges while leaving authentic high-frequency features crisp and defined.
