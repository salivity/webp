Extract Metadata, ICC, and Frames with webpmux

The webpmux utility, part of Google's libwebp library, is a command-line tool designed for manipulating WebP container files. This guide details how to use webpmux to quickly extract ICC color profiles, EXIF data, XMP metadata, and individual frames from animated WebP images.

Extracting ICC Color Profiles

To extract an embedded ICC color profile from a WebP image, use the -get icc option. The extracted file is saved in the raw ICC format:

webpmux -get icc input.webp -o profile.icc

If the source image does not contain an ICC profile, webpmux will return an error stating that the chunk is not found.

Extracting EXIF Metadata

WebP files can store standard camera and image metadata in an EXIF chunk. To dump this data into a standalone EXIF payload file, run:

webpmux -get exif input.webp -o metadata.exif

The resulting file can then be parsed or viewed using metadata inspection tools like exiftool.

Extracting XMP Metadata

XMP metadata contains extensible metadata properties, often added by image editing software. Extract the raw XML-based XMP chunk using the -get xmp option:

webpmux -get xmp input.webp -o metadata.xmp

Extracting Specific Frames from an Animated WebP

For animated WebP images, webpmux allows you to extract individual frames as independent WebP images. Use the -get frame option, specifying the 1-based index N of the frame you want to extract:

webpmux -get frame N input.webp -o frame_N.webp

For example, to extract the third frame:

webpmux -get frame 3 animation.webp -o frame_3.webp

The extracted output is a valid, single-frame WebP image retaining the visual parameters of that specific animation step.
