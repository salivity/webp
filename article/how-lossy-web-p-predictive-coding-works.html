How Lossy WebP Predictive Coding Works

Lossy WebP achieves high compression efficiency by using spatial intra-prediction derived from the VP8 video codec. Instead of encoding raw pixel data, the format predicts pixel values within a given block based on previously decoded neighboring pixels located above and to the left. The encoder then only stores the difference between the prediction and the actual image—known as the residual—which requires significantly fewer bits to represent.

Block-Based Image Partitioning

The WebP encoder divides the image into a grid of macroblocks, typically measuring 16x16 pixels for luminance (brightness) and 8x8 pixels for chrominance (color). For regions containing complex details or fine textures, 16x16 luma macroblocks can be further subdivided into sixteen individual 4x4 sub-blocks. Because compression proceeds in raster-scan order (from left to right, top to bottom), the blocks directly to the left, above-left, directly above, and above-right of the current target block have already been processed and reconstructed before the current block is evaluated.

Prediction Boundaries

Predictive coding strictly uses the reconstructed boundary pixels of adjacent blocks rather than the original source pixels. Using reconstructed pixels ensures that the decoder, which lacks the original uncompressed source, can replicate the exact same prediction values generated by the encoder. Specifically, the prediction functions read:

  • The row of pixels directly above the current block.
  • The column of pixels directly to the left of the current block.
  • The single pixel sitting diagonally at the top-left corner.

Intra-Prediction Modes

WebP analyzes the block's content and chooses one of several mathematical prediction modes to approximate the current block's layout.

16x16 Luma and 8x8 Chroma Modes

For smooth or uniform regions, WebP evaluates four primary prediction modes:

  • DC Prediction: Computes the arithmetic average of the adjacent pixels from the top row and left column, filling the entire block with this single average value.
  • Horizontal Prediction (H_PRED): Extends the column of pixels directly to the left horizontally across every row of the block.
  • Vertical Prediction (V_PRED): Extends the row of pixels directly above vertically down through every column of the block.
  • TrueMotion (TM) Prediction: An advanced gradient-preserving mode derived from the VP3/VP8 codecs. It estimates pixel values using the formula Pixel = Top[x] + Left[y] - TopLeft. This models linear brightness shifts and continuous gradients across the block.

4x4 Luma Sub-Block Modes

For sharp edges and high-frequency textures, 4x4 sub-blocks support nine directional prediction modes. Alongside DC, Horizontal, and Vertical modes, this includes several diagonal angles (such as Diagonal Down-Left, Diagonal Down-Right, Vertical-Right, and Horizontal-Down). These modes trace directional patterns across the boundary pixels into the 4x4 area to align with image contours.

Residual Calculation and Transmission

The encoder tests the available prediction modes and chooses the mode that minimizes both the visual error and the bit cost (rate-distortion optimization).

Once the optimal mode is selected:

  1. The predicted pixel values are subtracted from the actual pixel values to create a residual matrix.
  2. If the prediction is accurate, the residual values are near zero.
  3. The residual matrix undergoes a Discrete Cosine Transform (DCT) or a Walsh-Hadamard Transform (WHT) to convert spatial residuals into frequency coefficients.
  4. The coefficients are quantized to discard imperceptible data and finally compressed using arithmetic entropy coding alongside the selected prediction mode identifier.

At decode time, the WebP decoder reconstructs neighboring pixels, applies the specified prediction mode to build the baseline block, and adds the decoded residual to restore the final image data.
