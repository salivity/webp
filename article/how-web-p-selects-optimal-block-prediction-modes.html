How WebP Selects Optimal Block Prediction Modes

The WebP image format achieves high compression efficiency by using spatial intra-prediction borrowed from the VP8 video codec, predicting pixel values in a block using previously decoded boundary pixels. To select the optimal prediction mode for each image block, the WebP encoder analyzes neighboring pixels, generates residuals for each available candidate mode, evaluates the visual error and bit cost using distortion metrics and Rate-Distortion Optimization (RDO), and ultimately chooses the mode that produces the smallest file footprint with the least visual degradation.

1. Macroblock Partitioning

Before evaluating prediction modes, the encoder divides the image into macroblocks of 16x16 pixels. For the luma (brightness) channel, the encoder decides whether to treat the macroblock as a single 16x16 block or subdivide it into sixteen individual 4x4 sub-blocks.

  • 16x16 Partitioning: Best suited for flat, smooth, or low-detail regions.
  • 4x4 Partitioning: Utilized in complex regions containing sharp edges, textures, or fine details where a global 16x16 prediction would produce high residual errors.

The chroma (color) channels are always evaluated in 8x8 blocks corresponding to the standard 4:2:0 subsampling.

2. Generating Predictions from Boundary Pixels

For each block, the encoder attempts to predict pixel values using the reconstructed pixels immediately adjacent to its top and left borders.

For 16x16 luma and 8x8 chroma blocks, the encoder tests four primary modes:

  • DC Prediction: Fills the block with the average value of the top and left border pixels.
  • Vertical Prediction: Copies the row of pixels directly above down through each column.
  • Horizontal Prediction: Copies the column of pixels to the left across each row.
  • TrueMotion (TM) Prediction: Extends vertical and horizontal gradients simultaneously using the top-left corner pixel as a baseline, preserving smooth planar transitions.

For 4x4 luma blocks, the encoder evaluates 10 directional modes, including pure vertical, horizontal, DC, and several angled directions (such as diagonal-down-left and vertical-right) to align with fine edges.

3. Error Metrics: SAD and SATD

Once a candidate prediction is formed, the encoder subtracts it from the original block to produce a residual block. To quickly estimate the quality of a mode without performing a full transform and entropy-encoding pass, the encoder computes quick distortion metrics:

  • Sum of Absolute Differences (SAD): Calculates the absolute pixel-by-pixel difference between the original block and the predicted block.
  • Sum of Absolute Transformed Differences (SATD): Applies a fast Hadamard transform to the residual before summing absolute values. SATD better correlates with human visual perception and frequency-domain energy than raw SAD.

In fast encoding presets, the encoder uses these metrics to eliminate poor candidate modes early.

4. Rate-Distortion Optimization (RDO)

For high-quality or high-compression settings, the encoder selects the optimal mode using full Rate-Distortion Optimization (RDO). RDO measures the true trade-off between visual quality and required storage via a cost function:

\[\text{Cost} = \text{Distortion} + \lambda \times \text{Rate}\]

  • Distortion (\(D\)): The Sum of Squared Errors (SSE) between the original block and the fully reconstructed block (after Discrete Cosine Transform, quantization, and dequantization).
  • Rate (\(R\)): The exact number of bits required to encode both the choice of prediction mode itself and the quantized residual coefficients using the arithmetic entropy coder.
  • Lambda (\(\lambda\)): A Lagrange multiplier derived from the target quality/quantization parameter (\(QP\)) that balances fidelity against file size.

The encoder computes this cost for all viable modes and selects the one with the lowest overall cost score.

5. Search Acceleration and Pruning

Evaluating every mode with full RDO is computationally intensive. The WebP encoder utilizes configurable speed-versus-quality trade-offs:

  • Mode Pruning: Evaluates candidates using fast SATD first and only runs full DCT/RDO on the top two or three candidates.
  • Early Termination: If a candidate mode yields a near-zero residual with minimal bits, the encoder can terminate the search early for that block.
  • Spatial Correlation: Adjacent blocks often share the same directionality; the encoder prioritizes testing modes chosen by neighboring blocks to speed up convergence.
