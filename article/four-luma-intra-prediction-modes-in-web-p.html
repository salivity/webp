Four Luma Intra-Prediction Modes in WebP

WebP image compression relies on intra-frame prediction techniques adapted from the VP8 video format to minimize spatial redundancy. When encoding 16x16 luma (brightness) blocks, the WebP encoder estimates pixel values using surrounding reconstructed pixels before calculating the residual difference. This article breaks down the four primary intra-prediction modes used for these luma blocks: Vertical, Horizontal, DC, and TrueMotion.

1. Vertical Prediction (V_PRED)

Vertical prediction fills the entire block by copying the pixel values from the row directly above it. Each row inside the block duplicates the corresponding values of the boundary row above, projecting the data downward. This mode is optimal for image segments containing vertical edges, stripes, or vertical color gradients.

2. Horizontal Prediction (H_PRED)

Horizontal prediction functions similarly to vertical prediction but works from left to right. It takes the column of pixels immediately to the left of the target block and duplicates those values across every column inside the block. This mode is best suited for horizontal lines, horizons, and uniform horizontal textures.

3. DC Prediction (DC_PRED)

DC prediction calculates a single average value from the pixels directly above the block and the pixels directly to the left of the block. Once this arithmetic mean is determined, every pixel in the 16x16 block is assigned that identical value. DC prediction is ideal for flat, uniform regions with minimal texture, such as clear skies or smooth backgrounds.

4. TrueMotion Prediction (TM_PRED)

TrueMotion is a specialized prediction mode carried over from On2 Technologies' TrueMotion video codecs. It models two-dimensional gradients by evaluating the row above, the column to the left, and the top-left diagonal neighbor. For any pixel in the block, the predicted value is calculated using the formula:

\[\text{Pixel} = \text{Above} + \text{Left} - \text{Top-Left}\]

By accounting for both horizontal and vertical variations simultaneously, TrueMotion efficiently reconstructs complex gradients and lighting transitions that simple directional modes cannot match.

Mode Selection

During the compression process, the WebP encoder tests each of these four modes against the original block. It selects the mode that generates the smallest residual error (the difference between the predicted block and the actual image data), ensuring maximum compression efficiency with minimal data loss.
