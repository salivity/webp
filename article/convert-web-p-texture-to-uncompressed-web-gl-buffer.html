Convert WebP Texture to Uncompressed WebGL Buffer

Converting a compressed WebP image into an uncompressed WebGL buffer requires decompressing the WebP byte stream into raw pixel data (typically RGBA) and allocating an uncompressed GPU memory buffer via the WebGL API. Because GPUs cannot natively sample WebP bitstreams, the host environment must decode the image on the CPU or an asynchronous worker thread before passing the linear pixel array to the GPU via texImage2D or texSubImage2D.

1. Fetching and Decoding the WebP Data

The first step is downloading the WebP binary data and decoding it into a raw, linear pixel format:

  • Asynchronous Browser Decoding (createImageBitmap): The modern, high-performance approach uses fetch to retrieve the WebP blob, followed by createImageBitmap(). This decodes the WebP data off the main thread directly into an uncompressed GPU-ready raster format.
  • Canvas Fallback: Alternatively, you can load the WebP into an HTMLImageElement or draw it to an OffscreenCanvas using a 2D rendering context, and extract the uncompressed bytes via getImageData(), which yields a raw Uint8ClampedArray.
  • Software/WASM Decoding: In headless environments (like Node.js) or custom pipelines, native decoders (such as Google’s libwebp compiled to WebAssembly) decode the WebP bitstream into a raw Uint8Array containing sequential RGBA8888 values.

2. Pre-Upload Pixel Configuration

Before submitting the pixel data to WebGL, unpack parameters must be configured to match the texture's layout and coordinate space:

  • Vertical Axis Alignment: WebP defines the origin \((0,0)\) at the top-left corner, whereas WebGL texture coordinates \((0,0)\) start at the bottom-left. Set gl.pixelStorei(gl.UNPACK_FLIP_Y_WEBGL, true) to flip the rows during upload, or invert the V-coordinate in the vertex shader.
  • Alpha Premultiplication: If the WebP source contains transparency and the target shader expects premultiplied alpha, enable gl.pixelStorei(gl.UNPACK_PREMULTIPLY_ALPHA_WEBGL, true).
  • Row Alignment: If transferring raw byte arrays where the row width is not a multiple of 4 bytes, configure gl.pixelStorei(gl.UNPACK_ALIGNMENT, 1) to prevent memory stride corruption.

3. Allocating and Uploading to WebGL

Once the raw pixel buffer or ImageBitmap is ready, it must be bound to a target texture object and uploaded to the GPU:

  1. Create and Bind: Call gl.createTexture() followed by gl.bindTexture(gl.TEXTURE_2D, texture).
  2. Buffer Allocation and Transfer: Call gl.texImage2D with:
    • Target: gl.TEXTURE_2D
    • Level: 0 (base mip level)
    • Internal Format: Typically gl.RGBA (WebGL 1) or gl.RGBA8 (WebGL 2) to specify uncompressed 32-bit color.
    • Format and Type: gl.RGBA and gl.UNSIGNED_BYTE.
    • Source: Pass the ImageBitmap, HTMLCanvasElement, or a typed array (Uint8Array) containing the decompressed pixels.
  3. Configure Texture Filtering: Specify gl.TEXTURE_MIN_FILTER and gl.TEXTURE_MAG_FILTER using gl.texParameteri(). If mipmapping is required, call gl.generateMipmap(gl.TEXTURE_2D).

At this point, the GPU maintains the WebP's contents as an uncompressed, directly addressable 2D texture buffer in VRAM.
