Convert WebP to AVIF Without Visual Degradation

Converting a WebP image to AVIF can be done safely without noticeable visual degradation, provided you use the correct encoder settings. While transcoding from one lossy format to another mathematically discards data—a phenomenon known as generation loss—AVIF’s advanced compression capabilities allow you to preserve perceptual quality so thoroughly that the human eye cannot spot the difference.

The Mechanics of Lossy-to-Lossy Transcoding

If your original WebP file uses lossy compression, converting it to AVIF involves decoding the WebP into raw pixel data and then re-encoding that data into AVIF.

Because both formats use lossy compression, re-encoding will introduce mathematical loss. However, mathematical loss does not equal visible degradation. AVIF uses the AV1 video codec's intra-frame coding tools, which handle fine gradients, edges, and textures far more efficiently than WebP. As long as the target bitrate or quality factor is set high enough, the structural integrity of the image remains visually intact.

Converting Lossless WebP

If your source file is a lossless WebP:

  • To Lossless AVIF: There is zero degradation. The pixel data remains bit-for-bit identical, though file sizes may vary depending on the compression level.
  • To High-Quality Lossy AVIF: You will discard raw data to save file size, but you can achieve an image visually indistinguishable from the original at a fraction of the weight.

Best Practices to Prevent Visible Quality Loss

To ensure your converted AVIF files look visually identical to the source WebP, follow these guidelines:

  1. Target the Right Quality Factor (CRF): When using encoders like libaom or tools like FFmpeg and Squoosh, set your Constant Rate Factor (CRF) between 18 and 25. A CRF around 20 to 23 typically achieves transparency, meaning the output is perceptually identical to the source.
  2. Preserve Chroma Subsampling: Lossy WebP often uses 4:2:0 chroma subsampling. Ensure your AVIF encoder uses at least the same color fidelity (yuv420p or yuv444p for images with sharp color text or detailed graphics) to prevent color bleeding.
  3. Avoid Re-compressing Heavily Artifacted Sources: If the original WebP already displays visible compression artifacts, encoding to AVIF will either preserve those artifacts or require an unnecessarily large file size to prevent further smearing. Transcoding works best on high-quality source images.
  4. Retain Color Profiles: Ensure color profiles (like sRGB or Display P3) are carried over during conversion to avoid color shifts.

The Verdict

Yes, you can safely convert WebP to AVIF without noticeable visual degradation. By keeping quality targets sufficiently high and avoiding multiple conversion cycles, you can achieve smaller file sizes while preserving the visual fidelity of your original images.
